How we work

Story firstEvery feature has an id in docs/USER_STORIES.md. New ids must be free on main and in open PRs.
Status moves forwardIn PR = CI green, reviewed, "not tested" list. In build = on TestFlight, built from main. Device-tested = the owner ticked the checklist (only the owner sets it).
Claim, then buildA card with a branch is claimed; no commits for 2 days frees it. One build in Building at a time; builds come from main and get a tag.
Needs reviewFlag a card when someone has to look before it moves on: a mockup, a PR, a test result. Clear it when reviewed.
Done means device-testedCI green, independent review, then the owner's checklist on a real watch and phone. A build freezes when its PR says so.
Data lives in this page's shared store; chats read and write it with the artifact tools. The plan of record is docs/RELEASES.md in Slimslim/ML.WorkoutApp.
