# Coach conversation: what makes a result useful (30 min)

For a coach at the owner's box. No recording; the owner takes notes. Show 2 example results on the
phone (one AMRAP, one for time) after question 3.

**Context (2 min).** Rx Lab records a workout on the Apple Watch. Each time the athlete turns the
Crown, a segment ends, so we know how long each movement took, round by round. We don't count reps
yet. We want the result page to say something a coach would agree with.

**1. The first number (5 min)**
- After a class WOD, what is the first number you look at on an athlete's result?
- What do you ask them right after ("how did round 3 feel?", "where did you break?")?

**2. Splits (8 min)**
- If you had each movement's time per round, which pattern would you look for first?
- Can segment times alone tell a pacing problem from a strength problem? What else would you need
  (sets, reps per set, rest between sets, heart rate)?
- Is "the bike took 22 % longer from round 2 on, the step-ups stayed steady" useful, obvious, or wrong?

**3. Comparisons (5 min)**
- When is "vs last time" fair? Same weights only? Same scale only? How long ago is too long?
- Would you compare a movement across workouts (e.g. wall balls in two different WODs)?

**4. Silence vs guessing (5 min)**
- Would you rather the app say nothing than say something it can't back up?
- Which advice would you never want an app to give your athletes?

**5. One wish (5 min)**
- If the app could tell your athletes one thing after every class, what should it be?

**Notes:** first number; patterns; pacing vs strength; silence yes/no; never-say list; one wish.
